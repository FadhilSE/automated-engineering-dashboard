## 📌 Overview

A full-stack **microservices engineering management platform** designed to centralize project workflows into one modern dashboard.

It enables teams to manage:

✅ Projects  
✅ Tasks  
✅ Documents  
✅ Deadlines  
✅ Analytics  
✅ GitHub Activity

## ✨ Core Features

### 🔐 Authentication
- User registration
- Secure login system

### 📁 Project Management
- Create/manage projects
- Ownership roles
- Project summaries

### ✅ Task Management
- Task CRUD operations
- Status tracking
- Due dates
- Overdue alerts

### 📄 Document Center
- Upload files
- Download files
- Delete files

### 📊 Analytics Dashboard
- Project progress bars
- Task breakdown
- Upcoming deadlines
- Summary metrics

### 🔗 GitHub Integration
- Connect repository
- View recent commits
- Commit metadata

### 🌙 UI Enhancements
- Dark mode
- Search tasks
- Notifications
- Charts
